WoW is a Feeling

Description

A free addon manager for World of Warcraft: Forever. Browse addons, install them with one click, and keep them updated, all without opening a website. It's one small program, and when you close it, it's gone.

Objectives

  • Browse Forever addons you don't have yet, right in the app
  • Install, update and remove with one click
  • Pick up addons you already installed with another tool
  • Update the app itself, after it asks you first

The first time you open it

This app is free and isn't paying for code signing yet, so your system will warn you once.

  • Windows: if SmartScreen appears, choose More info, then Run anyway.
  • macOS: open it once, then go to System Settings, Privacy & Security, and choose Open Anyway.
  • Linux: make the AppImage executable, then run it. It finds Wine, Lutris, Bottles, Proton and Faugus installs.

Each release publishes its checksums, and you can read every line of the source.

What it connects to

GitHub, for the addon list, updates and most addon downloads. WoWInterface, for addons published there. ForeverDB's own site, if you install ForeverDB. Imgur and Postimages, for screenshots addon authors keep there. Nothing else, and it sends no telemetry. An addon's page can't make the app contact any other site.

Why some addons are missing

Addons published only on CurseForge, Wago or Tukui can't be listed, because those sites don't allow it without approval. You can still drop a downloaded zip onto the window to install it. When you search for one, the app suggests alternatives.
